# Pasal 12
(1) Pemerintah Daerah melaksanakan program Penanggulangan Kemiskinan berdasarkan RPKD.
(2) Program Penanggulangan Kemiskinan sebagaimana dimaksud pada ayat (1) terdiri atas:
a. program pengurangan beban pengeluaran masyarakat;
b. program peningkatan pendapatan masyarakat;
dan/atau c. program penurunan jumlah kantong Kemiskinan.
